# C# and .NET Backend Resources

## Knowledge

- [Microsoft Learn: A tour of C#](https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/)
  Official overview of the language, its type system, and its distinctive features. Use for: language-level questions and links to deeper topics.
- [Microsoft Learn: Build a Minimal API](https://learn.microsoft.com/aspnet/core/tutorials/min-web-api?view=aspnetcore-10.0)
  Official, current walkthrough of an ASP.NET Core HTTP API. Use for: routing, request binding, response results, and running an API.
- [Microsoft Learn: EF Core DbContext configuration](https://learn.microsoft.com/ef/core/dbcontext-configuration/)
  Official guidance on configuring the unit-of-work object and its lifetime. Use for: dependency injection and database setup.
- [Npgsql: EF Core provider](https://www.npgsql.org/efcore/)
  PostgreSQL provider documentation. Use for: the `Npgsql.EntityFrameworkCore.PostgreSQL` package and PostgreSQL-specific behavior.
- [Microsoft Learn: EF Core database providers](https://learn.microsoft.com/ef/core/providers/)
  Official provider catalog and compatibility guidance. Use for: understanding the boundary between EF Core and PostgreSQL's Npgsql provider.

## Wisdom (Communities)

- [ASP.NET Core discussions](https://github.com/dotnet/aspnetcore/discussions)
  Maintainer and practitioner discussion for framework behavior and design questions.
- [Npgsql GitHub discussions](https://github.com/npgsql/npgsql/discussions)
  Provider-specific community for PostgreSQL driver and EF Core integration questions.
