Lesson 3 · 30 minutes

Build a complete Todo API vertical slice.

The routes work. Now give them a resource, request DTOs, predictable status codes, and a store. We will preserve this HTTP contract when PostgreSQL replaces the in-memory state.

Mission connection: after this, the interesting change is not “how do routes work?” but “how does an async database-backed handler preserve the same contract?”

1. Replace Program.cs

Stop the current server with Ctrl+C, then replace the file with this. It is all in one file on purpose: first learn the moving parts, then organize them.

using System.Collections.Concurrent;

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

var todos = new ConcurrentDictionary<int, Todo>();
var nextId = 0;

app.MapGet("/health", () => Results.Ok(new { status = "ok" }));

app.MapGet("/todos", () =>
    Results.Ok(todos.Values.OrderBy(todo => todo.Id)));

app.MapGet("/todos/{id:int}", (int id) =>
    todos.TryGetValue(id, out var todo)
        ? Results.Ok(todo)
        : Results.NotFound());

app.MapPost("/todos", (CreateTodoRequest request) =>
{
    var title = request.Title.Trim();
    if (string.IsNullOrWhiteSpace(title))
    {
        return Results.ValidationProblem(new Dictionary<string, string[]>
        {
            ["title"] = ["Title cannot be blank."]
        });
    }

    var todo = new Todo(Interlocked.Increment(ref nextId), title, false);
    todos[todo.Id] = todo;

    return Results.Created($"/todos/{todo.Id}", todo);
});

app.MapPut("/todos/{id:int}", (int id, UpdateTodoRequest request) =>
{
    if (!todos.TryGetValue(id, out var existing))
    {
        return Results.NotFound();
    }

    var title = request.Title.Trim();
    if (string.IsNullOrWhiteSpace(title))
    {
        return Results.ValidationProblem(new Dictionary<string, string[]>
        {
            ["title"] = ["Title cannot be blank."]
        });
    }

    var updated = existing with { Title = title, IsComplete = request.IsComplete };
    todos[id] = updated;

    return Results.Ok(updated);
});

app.MapDelete("/todos/{id:int}", (int id) =>
    todos.TryRemove(id, out _)
        ? Results.NoContent()
        : Results.NotFound());

app.Run();

public record Todo(int Id, string Title, bool IsComplete);
public record CreateTodoRequest(string Title);
public record UpdateTodoRequest(string Title, bool IsComplete);

2. Read the five new ideas

C# / ASP.NET CoreWhat it doesGo-shaped mental model
recordA compact immutable data type with value equality.A DTO struct, but with generated value semantics.
CreateTodoRequest requestBinds the JSON body to a typed object.Like decoding into a request struct, supplied to the handler.
{id:int}Requires the path segment to parse as an integer.Router constraint plus typed path parsing.
existing with { ... }Copies a record while changing named properties.Create an updated value rather than mutate the old one.
ConcurrentDictionary + InterlockedSafe shared in-memory map and ID increment.A safer teaching substitute for a map plus mutex/counter.

Why not List<Todo>? ASP.NET Core handles requests concurrently. A plain mutable list would smuggle a race into the first API you build. This store is only for learning: restart the server and all data disappears.

3. Exercise: prove the contract

Run dotnet run in TodoApi, keeping your reported port if it remains 5229. Then run these in a second terminal:

curl -i -X POST http://localhost:5229/todos \
  -H 'Content-Type: application/json' \
  -d '{"title":"Learn Minimal APIs"}'

curl -i http://localhost:5229/todos

curl -i -X PUT http://localhost:5229/todos/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"Learn Minimal APIs","isComplete":true}'

curl -i -X DELETE http://localhost:5229/todos/1

curl -i http://localhost:5229/todos/1

You should observe, in order: 201 Created, 200 OK, 200 OK, 204 No Content, then 404 Not Found. Use the Todo API contract as the authoritative expected behavior.
