2. Replace Program.cs

var user = new User("Ada", "ada@example.com");

Console.WriteLine(user.Greeting());

public sealed class User(string name, string? email)
{
    public string Name { get; } = name;
    public string? Email { get; } = email;

    public string Greeting() => $"Hello, {Name}";
}

Expected output: Hello, Ada.

SyntaxMeaningGo translation

string?A nullable reference: it may contain null.Closest in intent to an optional pointer, checked by tooling/compiler analysis.
new User(...)Construct an object.Like allocating/initializing a struct, but class is a reference type.
public string Name { get; }Read-only property.An exported field with controlled access; a common C# API surface.
=>Expression-bodied member.Compact one-expression function body.

4. The async shape you will use in the API

static async Task<User?> FindUserAsync(string email, CancellationToken cancellationToken)
{
    await Task.Delay(10, cancellationToken); // stand-in for database I/O
    return email == "ada@example.com" ? new User("Ada", email) : null;
}

Think of Task<T> as “a future result of type T”. Unlike a goroutine, async/await principally gives a non-blocking composition model for I/O. In web handlers, accept and pass a CancellationToken to database calls.
