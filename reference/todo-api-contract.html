Quick reference

In-memory Todo API contract

RequestSuccessMeaning
GET /todos200 + arrayList all todos ordered by ID.
GET /todos/{id}200 + todoReturn one todo; 404 if absent.
POST /todos
{"title":"…"}		201 + todoCreate a todo; 400 for a blank title.
PUT /todos/{id}
{"title":"…","isComplete":true}		200 + todoReplace the fields in this small API; 404 if absent.
DELETE /todos/{id}204Remove the todo; 404 if absent.
State boundary: this API's data lives only in process memory. Restarting the server empties it. Its routes and status-code contract will stay useful when the store is replaced with PostgreSQL.
