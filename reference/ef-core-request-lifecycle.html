StepCode shapeReason
1. Construct contextAddDbContext<TodoDbContext>(...)ASP.NET Core creates one scoped context per request.
2. Readdb.Todos.AsNoTracking()Query without tracking when the result will not be edited.
3. Create/update/deletedb.Todos.Add(...), mutate tracked entity, or Remove(...)Describe intended persistence changes.
4. Commitawait db.SaveChangesAsync(ct)Execute the pending SQL changes, respecting request cancellation.
5. RespondResults.Created, Results.Ok, etc.Keep the HTTP contract independent from the storage mechanism.
Boundary: the EF entity is a mutable class used by the ORM. The request/response shapes are immutable records. Do not expose the persistence entity as your permanent public API by accident.
