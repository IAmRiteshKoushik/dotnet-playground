# Mission: C# and .NET backend fluency

## Why
Become productive enough in C# and .NET to build backend services, then learn deeper details while shipping. The immediate proof is a small HTTP API backed by PostgreSQL, using prior Go backend experience as the starting point.

## Success looks like
- Read and write ordinary C# application code without translating every line from Go.
- Build, run, and debug a small ASP.NET Core API locally.
- Persist and retrieve data from PostgreSQL through a deliberately small data-access layer.

## Constraints
- Move quickly: practical language essentials, then learn the rest while building.
- Explain by contrast with Go where that reduces friction.
- Prefer one small vertical slice over a broad framework tour.

## Out of scope
- Desktop, mobile, game, and enterprise-framework coverage.
- Advanced language features before they become useful to the API.
